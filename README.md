# 2027.science

An experimental boundary-pushing website that redefines web development through dynamic technology integration and Claude Flow automation.

## Vision

This is not just another website. It's a living laboratory where each page is uniquely crafted with cutting-edge technologies:

- **Dynamic Technology Selection**: Each page uses whatever technologies best serve its purpose
- **No Framework Constraints**: Free from the limitations of single-framework approaches
- **Experimental Technologies**: WebGPU, WebGL, WebXR, WASL, and emerging web standards
- **Claude Flow Integration**: Automated development and deployment through advanced AI coordination
- **Boundary-Pushing Design**: Best viewed with Canary browsers and experimental features enabled

## Architecture

- **Server**: Custom Node.js server with dynamic routing and middleware
- **Client**: Technology-agnostic frontend with per-page optimization
- **Development**: Git worktrees for parallel development streams
- **Deployment**: Cloudflare Workers/Pages via Wrangler
- **Automation**: Claude Flow swarm coordination for development tasks

## Development Philosophy

> "Every page is a canvas, every technology a brush, every boundary meant to be broken."

This project embraces:
- **Technological Anarchy**: Use whatever works best
- **Creative Destruction**: Rebuild pages with better approaches
- **Continuous Evolution**: Never settle for "good enough"
- **Experimental Freedom**: Crash often, learn always

**⚠️ Warning**: This site is designed to push the limits of web browsers. Enable experimental features for the full experience.
