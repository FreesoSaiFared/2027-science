# Native UI Replacements for MediaWiki-style Pages

- Footnote popups: Popover API + Anchor Positioning.
- Search/result highlights: CSS Custom Highlight API.
- Infobox/card layout: container queries and style queries.
- Collapsible sections: details/summary or dialog where modal.
- Page transitions: View Transitions API.
- Sticky table of contents: CSS sticky + scroll-state queries when available.
