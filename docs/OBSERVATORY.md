# Observatory

The Observatory skeleton searches for under-translated material, especially Chinese-language sources, and produces original English discovery cards with source links. No server processing is enabled by default.

## Consent lifecycle

1. Mask stays local by default.
2. A user may explicitly donate a redacted quest profile: interests, languages, optional constraints, and expiry.
3. Donation acceptance is shape validation only until durable storage is intentionally configured.
4. Revoke clears any future stored donation record; the bootstrap route reports success even when no store exists.
5. Results are shelf items: title, source URL, source language, WOW score, English-gap score, and original summary.

## Copyright boundary

The Observatory does not publish full translated article clones by default. Output should be summary-and-link, commentary, source quality signals, and discovery context.
